## Beschrijving

In deze opdracht heb ik 8 basis layouts gemaakt met CSS. Het doel was om te oefenen met verschillende layout modes en te leren welke techniek je het beste bij welke layout kunt gebruiken.



## Werkwijze

1. **Schetsen:** eerst heb ik de layouts op papier geschetst.
2. **Lijnen tekenen:** daarna heb ik in de schets de lijnen getekend die de indeling laten zien.
3. **Meten:** ik heb bekeken welke vakken er zijn en hoe groot ze ongeveer zijn.
4. **Techniek kiezen:** ik heb bepaald welke CSS het beste past bij elke layout.
5. **Bouwen:** tot slot heb ik de layouts gebouwd in HTML en CSS.

Ik heb dit samen met mijn groepje gedaan. We hebben alle 8 layouts samen doorgenomen en besproken. Ik heb er daarna zelf nog een paar extra layouts bij gemaakt, om zaken uit te proberen die ik nog moet leren.

## Kenmerken

- Ik heb vooral **CSS Grid** gebruikt, want de meeste layouts waren grid layouts.
- Semantische HTML als basis voor elke layout.
- grid-template-columns

## Wat heb ik geleerd

- Layouts eerst schetsen en meten maakt het kiezen van de juiste CSS makkelijker.
- Veel layouts zijn op te lossen met grid.
- Samenwerken helpt: door de layouts samen door te nemen zag ik meerdere manieren om hetzelfde te maken.
- ik moet zelf nog paar basic layouts begrijpen die ik nu bier zelf heb staan.
